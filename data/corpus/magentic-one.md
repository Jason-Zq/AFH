# Magentic-One 多智能体模式

## 定义

Magentic-One 是微软研究院提出的通用多智能体系统，目标是让一组专业化 Agent 在编排器指挥下解决开放式复杂任务——即那些步骤事先无法预知、需要边做边规划的任务。

## 架构：编排器 + 任务账本

Magentic-One 的中心是 Orchestrator（编排器），它维护一份"任务账本"（Task Ledger），记录：已知事实、需要查证的内容、当前计划、各 Agent 的进展与卡点。编排器据此动态决策下一步派谁做什么；发现进展停滞时会重写计划。任务完成后输出最终答案。

外围是若干专业 Agent，典型分工包括：

- **WebSurfer**：操作浏览器，搜索与读取网页；
- **Coder**：编写与调试代码；
- **FileSurfer**：浏览与处理本地文件；
- **ComputerTerminal**：执行命令行指令。

## 与固定编排模式的区别

顺序、并发、移交等模式的分工结构在构建时就确定了；Magentic 的调用关系由编排器在运行时按账本状态动态生成。这带来真正的开放性（能处理没见过的任务形态），也带来代价：每步决策都要模型调用，token 消耗与延迟显著高于固定流程，且对编排器所用模型的规划能力高度敏感。

## 基准与边界

Magentic-One 在 GAIA 等需要多步网页与文件操作的基准上取得了有竞争力的成绩，验证了通用架构的可行性。适用边界同样清晰：任务结构已知、步骤固定的场景（如"检索-分析-写作"流水线）用顺序编排更省、更稳；只有面对步骤无法预知的开放式任务时，动态编排的开销才物有所值。Microsoft Agent Framework 将该模式作为工作流的一种内置风格提供，与顺序/并发/群聊并列。
