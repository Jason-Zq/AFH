# 计算机操作 Agent

## 定义

计算机操作 Agent（Computer Use Agent）直接操纵图形界面完成任务：截屏观察屏幕，输出鼠标点击、键盘输入等动作，像人一样使用软件。它瞄准的是那些**没有 API、无法函数调用**的存量软件世界。

## 截图 + 坐标点击范式

典型循环：

1. 截取当前屏幕图像；
2. 多模态模型理解界面，决定下一步动作（点击某坐标、输入文本、滚动）；
3. 执行动作，回到第 1 步。

模型需要把"语义目标"（如"搜索按钮"）映射为像素坐标，这是该范式的核心难点：分辨率变化、界面改版、元素遮挡都会导致定位漂移。

## 浏览器操作

浏览器是最常见的受控环境：除了像素级操作，还可读取 DOM/无障碍树（accessibility tree），用元素引用代替裸坐标，稳定性显著更好。Playwright 一类的自动化框架常作为执行层，模型负责决策、框架负责可靠地点击。

## 与函数调用的差异

| 维度 | 函数调用 | 计算机操作 |
|------|----------|-----------|
| 接口 | 结构化、有契约 | 像素/DOM，无契约 |
| 可靠性 | 参数校验、错误明确 | 定位漂移、副作用隐蔽 |
| 适用范围 | 仅限提供 API 的系统 | 任何有 GUI 的软件 |
| 速度 | 毫秒级 | 每步需截图推理，秒级 |

工程上的共识：**能用函数调用就不用 GUI 操作**，计算机操作是覆盖长尾软件的兜底手段。

## 安全边界

- 沙箱隔离：在虚拟机或容器内运行，限制文件与网络可达范围；
- 不可逆操作（支付、发送、删除）必须人工确认；
- 防范提示注入：网页内容可能含有诱导模型乱操作的指令，截屏观察到的文字不应被当作可信指令来源；
- 全程录屏留痕，便于审计与回放。
