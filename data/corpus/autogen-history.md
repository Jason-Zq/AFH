# AutoGen 简史

## 起源

AutoGen 是微软研究院（Microsoft Research）主导开源的多智能体框架，论文与初版于 2023 年发布。它提出的核心命题是：复杂任务可以通过**多个智能体之间的对话**来完成，而不是靠单一 Agent 独自推理。

## 核心思想：对话式编排

AutoGen 把一切交互建模为"可对话的智能体"（Conversable Agent）之间收发消息：

- 智能体可由 LLM、人类、工具任意组合驱动；
- 典型配置是 Assistant（提议方案、写代码）与 UserProxy（执行代码、回传结果）结对循环；
- 通过 GroupChat 等模式扩展到多角色讨论，由一个管理器决定"下一个发言者"。

这种"编排即对话"的抽象简单灵活，迅速成为多智能体研究的事实标准之一，Magnetic-One 等通用多智能体系统即构建于其之上。

## 版本演进

AutoGen 0.2 系列以易用性见长；随后团队重构出事件驱动、基于 Actor 模型的新核心（0.4 系列），强化了异步、分布式与可观测性，并提供无代码的 Studio 工具。重构期的 API 断裂是社区讨论较多的教训。

## 并入 MAF 的脉络

随着微软内部 Agent 技术栈增多，AutoGen（研究血统、多智能体对话）与 Semantic Kernel（工程血统、企业编排）走向合流：二者被整合为统一的 **Microsoft Agent Framework（MAF）**，AutoGen 的多智能体编排能力成为框架的一部分，原项目转入维护状态。对使用者的启示是：多智能体对话模式沉淀了下来，但 API 应以 MAF 为准重新学习，不宜在新项目中直接绑定旧版 AutoGen。
